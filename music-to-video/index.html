Features

타임라인에서 한눈에 편집

처음부터 복잡한 영상 편집을 배울 필요 없이, 보이는 클립을 끌어 시간과 순서를 조절할 수 있습니다.

♫

여러 음원과 파형

FLAC, WAV, MP3를 등록하고 파형을 보며 배치합니다. 음원 사이 빈 구간은 무음으로 처리합니다.

▣

이미지 위치와 움직임

사진의 위치와 배율을 조절하고, 시작·끝 화면을 지정해 부드러운 움직임을 만듭니다.

T

문구와 스타일

여러 줄 문구를 원하는 시간에 올립니다. 글꼴, 색상, 외곽선, 반투명 배경을 바꿀 수 있습니다.

↔

이미지 전환

즉시 전환, 크로스 디졸브, 검정 페이드, 좌우 슬라이드 중에서 선택합니다.

How it works

음원 등록부터 MP4 저장까지

파일을 등록하고, 타임라인에서 길이를 맞춘 다음 내보내면 됩니다.

1

음원과 사진을 가져오세요

+ 음악으로 음원을 등록하면 파형을 분석합니다. + 이미지로 사진을 추가하고 각 목록에서 타임라인으로 끌어 놓으세요.

한 음악 트랙 안에서 클립끼리 겹치지 않으며, 이미지는 기본 5초로 배치됩니다.

2

시간과 문구를 다듬으세요

클립 가운데를 끌어 이동하고 양끝을 끌어 사용 시간을 바꿉니다. 텍스트를 올린 뒤 오른쪽 속성에서 문구와 표시 시간을 조절하세요.

스냅을 켜면 가까운 클립 경계에 붙습니다. 드래그 중 Alt를 누르면 잠시 해제할 수 있습니다.

3

MP4로 완성하세요

MP4 내보내기에서 파일 이름과 저장 폴더를 고른 뒤 영상을 만듭니다. 진행률을 확인하거나 작업을 취소할 수 있습니다.

H.264 · 1920×1080 · 30fps · AAC 320kbps. 기존 파일은 자동으로 덮어쓰지 않습니다.

Made for simple edits

원본 파일은 그대로 두고 작업합니다

프로젝트 저장

편집 내용은 JSON 프로젝트로 저장합니다. 원본 음원과 이미지를 직접 변경하지 않습니다.

사진 비율 유지

EXIF 회전과 투명 PNG를 반영하고 남는 화면은 검정으로 채웁니다.

로컬에서 처리

영상 만들기는 PC의 FFmpeg로 진행합니다. 작업용 미디어를 외부 서버로 업로드하지 않습니다.

안전한 결과 저장

임시 출력이 완성된 후 최종 파일로 옮기고, 같은 이름의 기존 결과를 덮어쓰지 않습니다.

첫 영상을 만들어 보세요.

Google Drive에서 Windows용 배포 파일을 내려받으세요. 압축 파일이라면 전체를 풀고, 폴더 안의 MusicToVideo.exe를 실행하세요.

실행 파일과 함께 제공된 폴더·파일을 같은 위치에 보관하세요. 프로그램을 옮길 때도 배포 폴더 전체를 함께 옮겨야 합니다.
