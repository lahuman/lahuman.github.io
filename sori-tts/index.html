sori-tts

sori-tts 상세 정보 바로가기

텍스트를 서버에 보내지 않고, 내 PC에서 바로 한국어 음성을 만드세요. 로그인도 인터넷도 필요 없습니다.

Supertonic 3 기반 오프라인 한국어 TTS 입니다.

주요 기능

  • Supertonic 3 기반 로컬 CPU 음성 합성
  • 여성 5개, 남성 5개, 특별 남성 1개 음성 선택
  • 0.5×~2.0× 속도 조절
  • 최대 10,000자 입력과 문단별 누적 진행률 표시
  • 생성 결과 미리듣기와 WAV 저장
  • 긴 생성 작업 취소
  • 앱 중복 실행 방지
  • 생성 텍스트와 오디오를 외부 서버로 전송하지 않는 오프라인 실행

v1.0.0 사용 방법

  1. 배포 ZIP의 압축을 새 폴더에 풉니다.
  2. 폴더 안의 SoriTTS.exe를 실행합니다. EXE만 따로 이동하면 실행되지 않습니다.
  3. 읽을 텍스트, 음성, 속도를 선택하고 음성 생성을 누릅니다.
  4. 전체 진행률이 100%가 되면 저장 전에 미리 듣거나 WAV 저장을 누릅니다.

생성 속도는 CPU 성능과 텍스트 길이에 따라 달라집니다. 긴 WAV는 전체 파일을 메모리에 미리 올리지 않고 필요한 부분부터 재생합니다.

지원 환경:

  • Windows 10/11 x64
  • 인터넷 연결 불필요
  • 배포 폴더 전체를 유지할 수 있는 디스크 공간

개발 환경에서 실행

필수 환경:

  • Windows 10/11 x64
  • Node.js 22
  • Microsoft Visual C++ 2015-2022 Redistributable (x64)
  • 최초 모델 다운로드를 위한 인터넷 연결
